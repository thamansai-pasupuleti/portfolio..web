# Personal Portfolio Website

A simple personal portfolio webpage created as a first-year Web Development activity using **HTML5 and CSS3**.

## About the project

This website introduces a student and presents their interests, skills, sample projects, and contact information in one place.

## Sections

- Home / introduction
- About me
- Skills and learning interests
- Projects
- Contact and social links

## Technologies used

- HTML5 — webpage structure and content
- CSS3 — colors, spacing, layout, and responsive styling

## Files

- `index.html` — main webpage
- `style.css` — styles used by the webpage

## Run locally

1. Download or clone this repository.
2. Keep `index.html` and `style.css` in the same folder.
3. Open `index.html` in a web browser. You can also use the Live Server extension in Visual Studio Code.

## Deployment

This project can be hosted free using GitHub Pages:

1. Upload both files to the root of a GitHub repository.
2. Open **Settings → Pages**.
3. Select **Deploy from a branch**, choose `main` and `/(root)`, then save.
4. Open the published URL shown on the Pages settings screen.

## Customization

Replace the sample name, email address, profile details, and social links with your own information before submitting.
